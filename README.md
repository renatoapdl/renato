# Portfólio Pessoal - Renato Abreu

Landing page pessoal apresentando minha trajetória profissional, projetos e interesses.

## 🌐 Acesso ao Site

**Link:** [https://renatoapdl.github.io/renato/](https://renatoapdl.github.io/renato/)

## 📋 Sobre o Projeto

Site pessoal desenvolvido com HTML, CSS puro, apresentando:

- **Quem sou eu** - Apresentação pessoal e profissional
- **Redes Sociais** - Links para canais de contato
- **Família** - Um pouco sobre minha vida pessoal
- **Música** - Bandas que acompanho com páginas dedicadas
- **Trabalho** - Rádio Observatório Espacial do Nordeste (ROEN)
- **Artigos** - Textos e reflexões sobre tecnologia

## 🗂️ Estrutura do Projeto

```
renato/
├── index.html              # Página principal
├── artigos.html            # Página de artigos
├── css/
│   └── style.css           # Estilos globais
├── assets/
│   ├── favicon.ico         # Ícone do site
│   ├── foto.png            # Foto de perfil
│   └── images/
│       ├── social/         # Ícones de redes sociais
│       ├── bandas/         # Imagens de bandas
│       └── pages/          # Imagens das páginas
├── pages/

├── README.md               # Este arquivo
└── LICENSE                 # Licença
```

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (com flexbox)
- Google Fonts (Fraunces, Kaushan Script)
